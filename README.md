# 文档核验中心 V2 AI 版（离线保密 · 全息渐变）

> **纯本地优先、可选本地 AI、强保密的文档低级错误检查工具。**
> Word / Excel / PDF 文档逐层扫描 → 格式 / 文字规范 / 语句通顺度 / 行业词库 / AI 语义五级核验
> → 实时进度 + AI 思考日志 → 一键导出 Word 检测报告。
>
> 所有处理默认在本机完成；AI 核验可选用 **本地 Ollama（零联网）** 或显式配置的
> 联网 OpenAI 兼容接口；自学习仅学习**用户人工确认正确**的内容，AI 绝不自动采集。

---

## 一、产品定位

一份合同、一份标书、一份评估报告，往往因「全角空格」「编号断裂」「公式报错」
「金额单位不统一」「语句不通顺」这类低级错误影响专业度。本工具基于本地规则引擎 +
可选本地大模型，对 `.docx` / `.xlsx` / `.pdf` 文档做逐层扫描，定位问题并生成可归档的
Word 检测报告。

| 维度 | 说明 |
| --- | --- |
| 支持格式 | Word `.docx`、Excel `.xlsx`（含 `.xlsm`）、PDF（文本型，扫描件自动跳过）|
| 不支持 | `.doc` / `.xls`（旧版 OLE）、加密 / 损坏文档 → 友好提示并跳过，不中断批量 |
| 检测方式 | 本地规则引擎（零联网）+ 可选 AI 语义核验（本地 Ollama / 联网接口）|
| 前端 | React 单页应用，全息渐变主题（holo-bg / 玻璃拟态 / 渐变按钮）|
| 后端 | FastAPI，仅监听 `127.0.0.1:8501`（本机回环）|
| 输出 | 界面可视化统计 + 可下载的 Word 检测报告（`.docx`）|

## 三、离线合规与隐私声明（重点）

1. **零联网核心**：规则检测、词库匹配、语句通顺度检测、报告生成全部本地完成；
   后端 FastAPI 仅监听 `127.0.0.1`，无任何遥测、无 CDN、无外链资源（React 构建产物
   `static/` 全量本地化）。
2. **AI 核验默认关闭**：`settings.json` 的 `ai.enabled=false` 时全程零联网。
   - **本地 AI（Ollama）**：文档内容不出本机；
   - **联网 AI**：需用户显式填写接口地址与 API Key 才启用，仅将待核验文本发送至该接口。
3. **AI 不自动采集**：核验过程不产生任何学习数据；**本地AI自学习的样本只能由用户
   人工确认添加**（检测结果「标记正确」或自学习页手动粘贴），学习仅调用本地模型，
   记忆数据全部保存在本机 `config/ai_memory/`。
4. **学习记忆与思考日志不进报告**：Word 检测报告只包含检测结果（错误条目 / 位置 /
   类型 / 建议），不含 AI 思考过程日志与自学习样本数据。
5. **只读不写**：工具只检测、只标记、只生成报告，绝不自动修改原始文档。
6. **可审计**：规则 / 词库 / 学习数据均为本地明文 JSON / TXT，全部逻辑可人工审阅。

## 四、环境要求与快速开始

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 10/11（64 位），启动脚本为 `.bat` |
| Python | 3.9 ~ 3.13（推荐 3.11 / 3.13）|
| 内存 | ≥ 4 GB（启用本地 AI 推理建议 ≥ 16 GB）|
| 依赖 | `pip install -r requirements.txt`（FastAPI / python-docx / openpyxl / pypdf 等）|
| 本地 AI（可选） | 安装 [Ollama](https://ollama.com) 并拉取模型（如 `ollama pull qwen3:8b`），默认 `http://127.0.0.1:11434` |
| 前端（可选） | 仅开发 / 重新构建需要 Node.js 18+；运行直接使用 `static/` 产物 |

### 方式 A：双击启动（推荐）

双击根目录 **`启动工具.bat`**：

- 自动启动 FastAPI 服务（`http://127.0.0.1:8501`）
- 自动打开浏览器
- 关闭黑色窗口即停止服务

### 方式 B：手动启动

```bash
pip install -r requirements.txt
python app.py        # 启动后访问 http://127.0.0.1:8501
```

### 方式 C：重新构建前端（可选，开发用）

```bash
cd web
npm install
npm run build       # 产物自动输出 dist/，复制到 ../static/ 即可部署
```

> 已包含构建产物，日常使用无需 Node 环境。

## 六、本地AI自学习记忆（V2 新增）

> **原则：AI 绝不自动采集文档内容。** 样本只能来自用户人工确认。

1. **添加人工确认样本**：
   - 检测结果「错误详情」中对确认无问题的条目点 **「标记正确」**（原文片段自动入样本库）；
   - 或在「规则与词库统一管理 → 本地AI自学习」页手动粘贴一段确认正确的文档内容。
2. **立即学习**：调用**本地 Ollama**（强制本地模式、全程离线）提炼「标准表述」，
   生成**词库条目 + 校验规则**，自动合并到「自定义词库 / 自定义正则规则」的
   **「本地AI学习」分组**（来源标记：本地AI学习生成），启用状态即时参与后续检测。
3. **管理**：样本查看 / 启用禁用 / 删除 / 单条学习；学习产出词条与规则可
   启用禁用 / 删除（同步修改词库与规则文件）；**总开关**一键关闭自学习；
   **批量清空**仅删除学习生成的数据，**不影响用户手动导入或编写的规则词库**。
4. **算力不足友好提示**：模型未启动 / 响应超时 / 思考链解析失败等，均给出
   中文可操作提示（如「请启动 Ollama」「换用官方 qwen3 系列模型」），不中断其它功能。
5. **数据与报告**：样本与学习记录保存在本机 `config/ai_memory/`；学习记忆
   **不进入检测导出报告**。

上传 / 扫描后任务后台异步执行，等待页实时展示：

- **进度条 + 阶段指示**（7 阶段）：文件解析 → 页码定位 → 格式错误检测 →
  语句通顺度检测 → 行业词库规则匹配 → 结果汇总 → AI 智能核验；进度真实，

- **AI 思考过程动态面板**：实时滚动日志（「正在解析PDF文档提取文本」「正在读取docx

- **取消核验**：终止任务并清空该任务缓存，已完成部分不写入结果库。
- **完成自动跳转**错误详情；核验未完成时禁止跳转报告页；异常中断显示错误与
  已完成进度。

## 九、AI 智能核验与智能创建

### AI 智能核验（可选，默认关闭）

规则检测完成后可追加 **AI 语义级核验**（前后矛盾 / 表意不清 / 逻辑不通等规则检不出的问题）：

- **本地 AI（零联网）**：Ollama + 本地模型（推荐 `qwen3:8b`，`think` 参数可控）。
- **联网 AI（OpenAI 兼容）**：DeepSeek / 通义 / Kimi / OpenAI 等接口。
- 自动扫描本机已安装模型，配置的模型不在本机时自动同步切换。
- 按 `max_chars` 分段核验（`max_requests` 上限保护），单段失败降级为提示条目，不中断任务。
- 命中问题以「AI 智能核验」条目进入明细与报告；支持参考知识注入（上传的行业标准 / 术语定义）。

### AI 智能创建

- **对话式**：自然语言描述需求 → 生成词库分组 + 校验规则（预览后落盘）。
- **文档自建**：上传规范 / 标准 / 示例文档 → 两段式生成（要点 → 结构化 JSON），
  对本地 CPU 推理做了输出截断容错与自动重试。

## 十一、常见问题

**Q1：启动后页面打不开？**
确认 `python app.py` 正常启动且访问 `http://127.0.0.1:8501`；端口被占用时先关闭旧进程。

**Q2：AI 核验很慢或报错？**
本地 CPU 推理本身较慢（单文件约 1-5 分钟）；若报「连接失败」请先启动
Ollama（`ollama serve`）；若报「思考链解析失败 / 响应异常」，请换用官方
`qwen3` 系列模型（自定义 deepseek tag 的思考链无法硬禁）。

**Q3：自学习样本怎么来的？**
只来自你的主动操作：检测结果「标记正确」或自学习页手动粘贴。AI 不自动采集任何文档内容。

**Q4：工具会修改我的原文档吗？数据会上传吗？**
不会修改原文档。默认零联网；仅在显式启用联网 AI 时，待核验文本才发送至你配置的接口。

**Q5：批量清空自学习记忆会误删我的规则吗？**
不会。清空仅删除来源为「本地AI学习生成」的词条与规则，手动导入 / 编写的规则词库不受影响。

**Q6：能处理多大的文件？**
单文件上限 100 MB（`rules.json` 的 `global.max_file_size_mb`），单文件问题上限 800 条，可配置。
