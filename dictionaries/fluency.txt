#   行格式：正则|说明|灵敏度|等级
#   正则      Python 正则，按【句】匹配（句 = 以 。！？；!?; 切分后的片段），
#            支持 ^ 句首 / $ 句尾锚定；模式内可使用 | 交替符（解析时自右向左切分）

#   等级      命中提示等级：low=建议优化（弱提醒）/ high=强制复核；
#            缺省时取对应规则的 severity
#   缺失段自动取默认：灵敏度 normal、等级随规则
# 规则键约定（fluency 检测段）：
#   fl_logic     单句逻辑断裂

#   fl_order     语序混乱
#   fl_repeat    重复赘述
#   fl_conj      关联词搭配错误
