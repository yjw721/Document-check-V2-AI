文档文字规范 / 表述问题检测 —— 本地词库使用说明
============================================================

本目录存放「文字规范检测」所用的全部本地词库。检测引擎（checkers/textnorm_checker.py）
只读取这些文本文件，做本地正则 / 词库匹配，**不联网、不调用任何外部大模型**。

------------------------------------------------------------------
一、文件清单与对应检测项
------------------------------------------------------------------
  colloquial.txt   不规范用词 / 口语化表述（正式公文禁止口头用语）
  redundant.txt    重复冗余词句（语义重叠语病，如 亲眼目睹 / 凯旋归来）
  confusable.txt   易混淆近义词误用（制定/制订、权利/权力、必须/必需…）
  ambiguous.txt    歧义句式 / 表意模糊词（相关、适当、若干…）+ 过长无标点长句
  typo.txt         中文错别字 / 常见易写错词语（错误写法|正确写法）
  en_typo.txt      英文拼写错误（错误拼写|正确拼写，整词匹配不区分大小写）
  abbrev.txt       非正式简称 / 自创缩写（含通用缩写白名单）
  units.txt        数量 / 单位表述不统一（非标准单位符号 + 万元/元混用）
  grammar.txt      中英文语法错误（正则模式|说明：句式杂糅 / 关联词误配 /
                   英文主谓一致、时态、冠词、比较级等）
  vocab.txt        中英文词汇搭配不当 / 用词错误（正则模式|说明：动宾搭配 /
                   语义赘余 / 不可数名词量词等）

------------------------------------------------------------------
二、文件格式（均可直接用记事本编辑，保存为 UTF-8）
------------------------------------------------------------------
  通用规则：
    · 以 # 开头的行是注释，不参与检测；
    · 空行忽略；
    · 修改后下一次检测自动生效（无需重启程序）；
    · 增删词条：直接加 / 删一行即可。

  各文件字段分隔符为英文竖线 | ：

  colloquial.txt   口语词[|建议书面表达]
  redundant.txt    冗余短语[|说明]
  ambiguous.txt    模糊词[|提示]
  typo.txt         错误写法|正确写法
  en_typo.txt      错误拼写|正确拼写      （整词匹配，不区分大小写）
  units.txt        正则模式|建议说明        （正则对文本不区分大小写匹配）
  grammar.txt      正则模式|问题说明        （中英文语法正则，大小写不敏感）
  vocab.txt        正则模式|问题说明        （词汇搭配正则，大小写不敏感）
  confusable.txt   词A|词B|辨析说明        （出现词A或词B任一即提示该组辨析）
  abbrev.txt       简称[|建议]             （-----WHITELIST----- 之后为不报警的缩写白名单）

------------------------------------------------------------------
三、检测性质说明（重要）
------------------------------------------------------------------
  本类检测基于本地词库与正则，属“疑似”筛查：
    · 命中的问题统一标记为【疑似表述不当/用词不规范，仅供人工复核】；
    · 不判定为确定性错误，最终是否修改由人工决定；
    · 可在界面“问题明细”中忽略误报或标记已处理。

------------------------------------------------------------------
四、示例：新增一条口语化词
------------------------------------------------------------------
  用记事本打开 colloquial.txt，在末尾加一行：
      溜号|离岗 / 擅离岗位
  保存后，下次检测“溜号”即会被提示为疑似口语化表述。

  示例：把“KG”加入白名单（不再提示）
      打开 abbrev.txt，在 -----WHITELIST----- 之后加一行：KG
      （说明：KG 较常见，是否加入白名单请按贵单位规范决定）
